# SCRIPTURA — Echo of Eden

A digital storytelling experience exploring biblical stories, humanity's fall, sin, judgment, and redemption through classical black-and-white engravings.

## About The Project

SCRIPTURA — Echo of Eden is an interactive visual journey through some of the most significant biblical events.

The project presents stories through atmospheric design, vintage illustrations, and a chapter-based experience that follows humanity's journey from the fall of Lucifer to redemption.

## Built With

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
